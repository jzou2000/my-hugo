    This package includes two pieces of HC-SR04 Ultrasonic Sensor that work with Arduino, ESP32, ESP8266, Raspberry Pi, or any 5V or 3.3V microcontroller. This sensor can be used to measure the distance to objects or used for obstacle avoidance.

    SPECIFICATION
    - Operating Voltage: 5V
    - Logic voltage: 3.3V or 5V
    - Trigger Input Pulse width: 10uS
    - Static current: Less than 2mA
    - Sensor angle: Less than 15 degrees
    - Detection distance: 2cm-450cm
    - High precision: Up to 3MM
    - Echo signal Output: TTL PWL signal
    - Operating frequency: 40Hz
    - Color: Blue
    - Size: 45*20*15 mm
    - Weight: 10g
